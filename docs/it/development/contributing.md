# Contribuire

I contributi sono benvenuti. In breve:

1. Apri (o scegli) una issue che descrive la modifica.
2. Crea un branch da un `main` aggiornato: `feat/<descrizione-breve>` oppure `fix/<descrizione-breve>`.
3. Fai commit piccoli in formato [Conventional Commits](https://www.conventionalcommits.org), in inglese.
4. Apri una pull request verso `main` con il template. Il merge è solo squash e il titolo della PR diventa il messaggio del commit, quindi deve essere un Conventional Commit valido.
5. I controlli `lint`, `typecheck`, `test` e `build` devono essere verdi.

Prepara la macchina con [Sviluppo in locale](./local) ed esegui i controlli elencati in [Test](./tests).

Il testo completo (in inglese), con le regole di protezione dei branch e il processo di rilascio, è in [CONTRIBUTING.md](https://github.com/ivanerricis/easysend/blob/main/CONTRIBUTING.md). Per segnalare una vulnerabilità vedi [SECURITY.md](https://github.com/ivanerricis/easysend/blob/main/SECURITY.md).
