# Contributing

Contributions are welcome. The short version:

1. Open (or pick) an issue that describes the change.
2. Branch from an up-to-date `main`: `feat/<short-description>` or `fix/<short-description>`.
3. Commit in small steps using [Conventional Commits](https://www.conventionalcommits.org), in English.
4. Open a pull request to `main` using the template. Merge is squash only and the PR title becomes the commit message, so it must be a valid Conventional Commit.
5. The checks `lint`, `typecheck`, `test` and `build` must be green.

Set up your machine with [Local development](./local) and run the checks listed in [Tests](./tests).

The full text, including the branch protection rules and the release process, is in [CONTRIBUTING.md](https://github.com/ivanerricis/easysend/blob/main/CONTRIBUTING.md). To report a vulnerability see [SECURITY.md](https://github.com/ivanerricis/easysend/blob/main/SECURITY.md).
