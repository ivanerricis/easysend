# EasySend

## Italiano

Applicazione web self-hosted per il trasferimento di file di grandi dimensioni, simile a WeTransfer.

Stato: lavori in corso, fase 0.

I requisiti completi sono in [docs/SPEC.md](docs/SPEC.md).

Nota per Windows: il progetto resta in `C:\` (non nel filesystem di WSL2). La raccomandazione di SPEC sezione 11-bis di usare WSL2 non si applica a questa installazione.

Licenza: MIT.

## English

Self-hosted web application for transferring large files, similar to WeTransfer.

Status: work in progress, phase 0.

Full requirements are in [docs/SPEC.md](docs/SPEC.md) (in Italian).

Windows note: the project lives in `C:\` (not in the WSL2 filesystem). The SPEC section 11-bis recommendation to use WSL2 does not apply to this setup.

License: MIT.
